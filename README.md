# 南京银行余额同步（Android）

这个 Android App 只读取南京银行余额短信，并通过 PebbleKit 把余额同步到 `AI Quota` 表盘。它不打开微信或支付宝，不使用无障碍服务、截图或 OCR，也不会执行任何支付操作。

## 支持范围

- 短信号码：`106980095302`（同时兼容手机显示为 `+86 106980095302`）
- 短信格式：`【南京银行】您尾号9434的账号于2026年08月08日13时37分支出274.00元，余额1152.29元，摘要：...`
- 表盘 UUID：`8083f2df-8a08-4dbf-b8fe-922936e6ab1e`

其他号码、其他银行或不符合上述格式的短信都会被忽略。金额以整数“分”发送，避免浮点误差。

## 使用

1. 安装 `app/build/outputs/apk/debug/app-debug.apk`。
2. 首次启动时授予“短信”权限。
3. App 会读取最近一条有效南京银行短信并发送到 Pebble；以后收到新短信时自动更新。
4. 如手表当时未连接，打开 App 后点击“重新发送已保存余额”。

## 构建与测试

```text
gradlew.bat testDebugUnitTest assembleDebug
```

短信内容和解析结果只保存在 App 私有 `SharedPreferences` 中，不上传网络。
