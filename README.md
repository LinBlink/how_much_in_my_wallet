# 银行卡余额同步（Android）

这个 Android App 从南京银行短信读取绝对余额，并从招商银行 App 通知读取每笔余额变动，再通过 PebbleKit 同步到 `AI Quota` 表盘。它不打开银行 App，不使用无障碍服务、截图或 OCR，也不会执行任何支付操作。

## 支持范围

- 短信号码：`106980095302`（同时兼容手机显示为 `+86 106980095302`）
- 短信格式：`【南京银行】您尾号9434的账号于2026年08月08日13时37分支出274.00元，余额1152.29元，摘要：...`
- 招商银行包名：`cmb.pb`（兼容魅族 `com.meizu.cloud` 代理推送）
- 招商银行收入：`您账户9653于08月30日13:07收款人民币0.01`
- 招商银行支出：`您账户9653于...发生快捷支付扣款，人民币0.01`
- 表盘 UUID：`8083f2df-8a08-4dbf-b8fe-922936e6ab1e`

其他号码、其他银行或不符合上述格式的通知都会被忽略。金额以整数“分”发送，避免浮点误差；招商银行通知按推送任务 ID 去重。

## 使用

1. 安装 `app/build/outputs/apk/debug/app-debug.apk`。
2. 首次启动时授予“短信”权限，并点击“开启招商银行通知读取权限”。
3. 在 Pebble 的 `AI Quota` 设置页中填写一次 `CMB current balance (CNY)`，保存为招商银行计算基准。
4. App 会读取南京银行绝对余额；以后收到招商银行收入/支出通知时，在基准余额上自动加减。
5. 表盘 `BANK` 显示已知南京银行与招商银行余额之和。
6. 如手表当时未连接，打开 App 后点击“重新发送所有已保存数据”。事件 ID 会防止重复加减。

## 构建与测试

```text
gradlew.bat testDebugUnitTest assembleDebug
```

短信、通知内容和解析结果只保存在 App 私有 `SharedPreferences` 中，不上传网络。
